# Security

This is a Bachelor research proof of concept, not production-grade infrastructure
for executing untrusted code. Run it locally on a disposable development system;
the trusted runner has Docker Engine access and the workbench API is not a
multi-user authenticated service. Do not expose the running stack directly to
the public internet. Replace default/example tokens and database credentials
with your own private local values before real use.

Please report suspected vulnerabilities privately through the repository's
GitHub **Security → Report a vulnerability** mechanism, if enabled. Do not put
credentials, exploit details, or private execution data in public issues.
